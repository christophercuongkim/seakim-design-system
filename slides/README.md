# Slide template

Internal-comms deck surface. 1280×720, `data-app="seakim"` (house clay accent),
dark only — decks are projected.

| File | Slide type | Use for |
| --- | --- | --- |
| `TitleSlide.html` | Title | Opens the deck. Wordmark, one statement, audience and date in mono. |
| `SectionSlide.html` | Section divider | Marks a new act. Number, 2px accent rule, one line. Nothing else. |
| `AgendaSlide.html` | Agenda | Numbered rows split by hairlines, current item in accent. Max 6 rows. |
| `StatSlide.html` | Numbers | 2–4 mono figures in a bordered grid, with the measurement source stated. |
| `ComparisonSlide.html` | Comparison | Two columns, hairline split. Accent fills the recommended side only. |
| `QuoteSlide.html` | Quote | One voice, attributed in mono. No ornamental quote marks. |

## Rules

- **Type floor is 20px** on a 1280px slide (≈30px at 1920). Body copy sits at 21–24px.
- One accent per slide, and only on the thing being argued for.
- Hairline borders and flat fills only — no shadows, no gradients, no rounded cards.
- Wordmark bottom-left, page number bottom-right, both in `--text-tertiary`.
- Numbers are IBM Plex Mono with tabular figures, and every figure names its source.
- No photography is used because none was supplied. Full-bleed imagery, when it
  exists, replaces the padded slide body entirely rather than sitting inside a card.
